# うごくスタンプメーカー

静止画のイラストをアップロードして動きを選ぶと、**LINEアニメーションスタンプ**用の APNG を作る Web アプリです。
処理はすべてブラウザ内で行うので、画像がサーバーに送られることはありません。

## できること

- **画像のアップロード**：PNG / JPEG / WebP。ドラッグ＆ドロップで複数枚まとめて読み込めます（最大24枚）
  - 白などの単色背景は自動で透明にできます（外周とつながった背景色だけを消すので、キャラ内部の白は残ります）
  - 透明な余白は自動で切り抜きます
- **動きの指定**（最大3つまで重ねられます。強さと1ループ中の回数も調整可）
  - ぴょんぴょん / ふわふわ / ゆらゆら / ぶるぶる / くるくる / どきどき / ぷにぷに / ぺこり / よちよち / ひょっこり
  - 登場系：ポン！ / スライドイン / じわっ、点滅：ちかちか
  - 動いても枠からはみ出さないよう自動で縮小（オフにもできます）
- **飾り**：キラキラ・ハート・あせ・ぷんぷん・音符
- **文字入れ**：上下の位置、色、大きさ、イラストと一緒に動かすかを選べます
- **プレビュー**：書き出しと同じコマ数・表示時間で再生します。背景（透過 / トーク画面 / 白 / ダーク）を切り替えたり、LINEと同じくループ回数で止めたりできます
- **書き出し**
  - 1個ずつ APNG で保存
  - セットを ZIP で保存：`01.png`〜`NN.png`（APNG）、`main.png`（240×240 APNG）、`tab.png`（96×74 PNG）

## LINEの規定への対応

| 項目 | 規定 | このアプリでの対応 |
| --- | --- | --- |
| 形式 | APNG・背景透過 | APNG で書き出し（UPNG.js） |
| サイズ | 最大 320×270px、縦横どちらかは270px以上 | 320×270 / 270×270 / 320×240 から選択 |
| コマ数 | 5〜20 | スライダーで 5〜20 に制限 |
| 再生時間 | ループ込みで最大4秒 | 合計 1〜4 秒から選択。各コマの表示時間を整数msで割り振り、合計がぴったりになるよう計算 |
| ループ回数 | 1〜4 | acTL チャンクの `num_plays` に書き込み |
| 容量 | 1個 300KB 以下 | 超えたら 256 → 32 色まで段階的に減色して収める。それでも超える場合は警告 |
| メイン画像 | 240×240 APNG | ZIP に `main.png` として同梱 |
| タブ画像 | 96×74 PNG | ZIP に `tab.png` として同梱（動き・飾りなしの静止画） |
| 個数 | 8 / 16 / 24 個 | それ以外の個数のときは警告 |

規定は変わることがあるので、申請前に [LINE Creators Market の制作ガイドライン](https://creator.line.me/ja/guideline/animationsticker/) も確認してください。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest
npm run build    # dist/ に静的ファイルを出力
```

`main` に push すると GitHub Actions がテスト・ビルドして GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

### 構成

```
src/
  lib/
    spec.ts      LINEの規定値・コマごとの表示時間の計算
    motions.ts   動きのプリセット（t=0〜1 の姿勢を返す関数）と合成
    effects.ts   キラキラなどの飾りの描画
    render.ts    1コマの描画（配置・はみ出し防止・文字）
    image.ts     背景除去・切り抜き
    apng.ts      APNG エンコード（減色による容量調整・ループ回数の書き込み）
    pipeline.ts  ブラウザでの読み込み〜書き出し〜ZIP化
  components/    プレビュー・設定パネル
  App.tsx        画面全体
tests/           vitest（表示時間の計算、動きのループ継ぎ目、APNG の書き出し→読み直し、背景除去、はみ出し防止）
```

動きを追加するときは `src/lib/motions.ts` の `MOTIONS` に、`t`（0〜1）と強さから姿勢（移動・回転・拡大・不透明度）を返す関数を足すだけです。
ループする動きは `t=0` と `t=1` で同じ姿勢になるようにしてください（テストで確認しています）。
